# Avatares EDUQuest — demo v0.1

Seis ilustraciones completas de 1024 × 1536 px en PNG RGBA. Personaje A y B mantienen su identidad visual en las tres variantes.

Los PNG se conservan como originales. Los WebP del mismo nombre, a 512 × 768 px, son las variantes optimizadas para la web. R09F01 entrega la apariencia inicial y R09F03 usa las seis variantes previstas en este documento.

| Nivel | Personaje A                               | Personaje B                               | Uso previsto                                     |
| ----- | ----------------------------------------- | ----------------------------------------- | ------------------------------------------------ |
| 1     | `assets/personaje-a-nivel-1.png`          | `assets/personaje-b-nivel-1.png`          | Apariencia inicial incluida                      |
| 2     | `assets/personaje-a-nivel-2-arcano.png`   | `assets/personaje-b-nivel-2-arcano.png`   | Fantasía arcana: 6 monedas, nivel mínimo 2       |
| 3     | `assets/personaje-a-nivel-3-espacial.png` | `assets/personaje-b-nivel-3-espacial.png` | Exploración espacial: 12 monedas, nivel mínimo 3 |

Los seis recursos se entregan como imágenes completas, no capas. Se ha pedido transparencia al generador; los bordes de iluminación incluyen una zona de alpha semitransparente. Revisar visualmente sobre los fondos reales de la aplicación y optimizar para web antes de publicarlos. Mantener encuadre y proporciones sin recortar cada personaje de forma distinta.

La elección del personaje no requiere guardar género. La adquisición y el equipamiento deben validarse en el servidor. Estas ilustraciones son originales para el concepto EDUQuest y no contienen referencias intencionadas a franquicias.
