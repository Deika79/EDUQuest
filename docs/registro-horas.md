## Criterios

- Registrar lectura, diseño, implementación, depuración, pruebas, documentación y revisión.
- Vincular cada sesión con una tarea RFTP cuando sea posible.
- Git demuestra cambios, pero no demuestra por sí solo tiempo dedicado.
- No marcar pruebas como ejecutadas sin comando, captura, resultado o evidencia equivalente.
