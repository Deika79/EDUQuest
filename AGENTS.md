# Instrucciones de trabajo para EDUQuest

- Leer `EduQuest_Plan_Maestro_DAW.md` antes de modificar el proyecto.
- No modificar el plan maestro original salvo petición explícita.
- Trabajar únicamente en el hito que David indique.
- No dar por realizadas tareas, pruebas, horas, commits, capturas ni entregas futuras.
- Mantener trazabilidad con los identificadores RFTP R01-R08 del plan.
- No generar la aplicación Laravel ni instalar dependencias durante la fase de propuesta.
- No conectar repositorios remotos, servicios externos, proveedores de IA ni despliegues sin indicación expresa.
- Preservar la arquitectura propuesta salvo que el centro exija cambios: PHP 8.4, Laravel 13, Vue 3, TypeScript, Inertia, Tailwind, shadcn-vue y MySQL 8.4.
- Usar sesiones, cookies CSRF y Policies para autorización.
- Tratar la IA como ayuda para borradores revisables, nunca como publicación automática.
- Registrar siempre el estado real: planificado, pendiente, ejecutado o probado.
